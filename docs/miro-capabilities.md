# Capacidades do Miro com Claude Code

Lista de 15 capacidades que o Claude Code pode te ajudar com o Miro:

1. **Criar boards** - Configurar novos quadros para projetos e times
2. **Gerenciar sticky notes** - Adicionar, organizar e agrupar post-its
3. **Criar diagramas de fluxo** - Montar fluxogramas e diagramas de processo
4. **Mind maps** - Estruturar mapas mentais para brainstorming
5. **Frameworks ágeis** - Configurar boards de Sprint, Kanban e Scrum
6. **Retrospectivas** - Montar templates de retrospectiva (4Ls, Start/Stop/Continue)
7. **User Story Mapping** - Organizar histórias de usuário em formato visual
8. **Wireframes e protótipos** - Criar esboços de interfaces e fluxos de UX
9. **Colaboração em equipe** - Estruturar sessões de trabalho colaborativo
10. **Templates personalizados** - Criar e documentar templates reutilizáveis
11. **Integrações** - Conectar Miro com Jira, Slack, GitHub e outras ferramentas
12. **OKRs e planejamento estratégico** - Montar quadros de objetivos e resultados
13. **Diagramas de arquitetura** - Desenhar arquiteturas de sistemas e infraestrutura
14. **Customer Journey Map** - Mapear a jornada do cliente
15. **Workshop facilitação** - Planejar e estruturar dinâmicas de workshop interativo
